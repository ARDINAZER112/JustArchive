📖 Pengenalan Java

Apa itu Java?

Java adalah bahasa pemrograman berbasis objek (OOP) yang dikembangkan oleh Sun Microsystems pada tahun 1995. Java dirancang untuk berjalan di berbagai platform dengan filosofi "Write Once, Run Anywhere" (WORA). Java menggunakan Java Virtual Machine (JVM) untuk mengeksekusi bytecode yang telah dikompilasi.

Mengapa Belajar Java?

  • Populer & Permintaan Tinggi - Java adalah bahasa paling dicari di industri
  • Platform Independen - Berjalan di semua sistem operasi
  • Object-Oriented - Konsep OOP fundamental untuk pengembangan software
  • Aman & Stabil - Digunakan oleh perusahaan Fortune 500
  • Rich Ecosystem - Ribuan library dan framework tersedia
  • Scalable - Cocok untuk aplikasi enterprise besar

Karakteristik Java

  • Simple - Sintaks yang mirip dengan C++ tapi lebih sederhana
  • Secure - Fitur keamanan built-in
  • Robust - Penanganan error yang baik
  • Multithreading - Mendukung concurrent programming
  • Dynamic - Loading class yang dinamis
  • Portable - Write once, run anywhere

Inheritance

Menengah

🎯 Tujuan

Pewarisan class di Java.

// Parent Class public class Hewan { public void suara() { System.out.println("Suara hewan"); } } // Child Class public class Kucing extends Hewan { @Override public void suara() { System.out.println("Meow"); } } // Penggunaan Kucing cat = new Kucing(); cat.suara(); // Polymorphism Hewan h = new Kucing(); h.suara();

Encapsulation

Menengah

🎯 Tujuan

Menyembunyikan detail implementasi dengan access modifiers.

public class BankAccount { private double balance; private String accountNumber; public BankAccount(String account) { this.accountNumber = account; this.balance = 0; } // Public Method public void deposit(double amount) { if (amount > 0) { balance += amount; } } public double getBalance() { return balance; } } BankAccount account = new BankAccount("1234"); account.deposit(100000); System.out.println(account.getBalance());

Interface

🎯 Tujuan

Try-Catch

Menengah

🎯 Tujuan

Menangani exception dengan try-catch.
