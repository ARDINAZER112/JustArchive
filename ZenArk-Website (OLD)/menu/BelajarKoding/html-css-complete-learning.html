📖 Pengenalan HTML & CSS

Apa itu HTML?

HTML adalah bahasa markup yang menyusun konten halaman web dengan tag dan elemen.

Apa itu CSS?

CSS adalah bahasa styling yang mengatur tampilan, warna, font, dan tata letak elemen HTML.

Mengapa Belajar HTML & CSS?

  • Fondasi dari semua website
  • Mudah dipelajari dan universal
  • Bekerja di semua browser tanpa instalasi
  • Penting untuk pengembangan web

📚 Tutorial HTML & CSS

Struktur Dasar

Pemula

🎯 Tujuan

Memahami struktur dasar HTML.

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <title>Judul</title> </head> <body> <h1>Halo!</h1> </body> </html>

Heading & Text

Pemula

🎯 Tujuan

Membuat heading dan paragraf.

<h1>Judul</h1> <h2>Sub Judul</h2> <p>Paragraf teks</p> <b>Bold</b> <i>Italic</i>

Link & Gambar

Pemula

🎯 Tujuan

Menambah link dan gambar.

<a href="url">Link</a> <img src="photo.jpg" alt="Deskripsi">

Warna & Font

Pemula

🎯 Tujuan

Styling warna dan font.

body { color: blue; font-family: Arial; font-size: 16px; }

Box Model

Menengah

🎯 Tujuan

Margin, padding, border.

.box { padding: 20px; margin: 10px; border: 2px solid #333; }

Transitions

Menengah

🎯 Tujuan

Animasi halus.

button { transition: 0.3s; } button:hover { transform: scale(1.1); }

Flexbox

Menengah

🎯 Tujuan

Layout dengan Flexbox.

.container { display: flex; justify-content: center; align-items: center; gap: 20px; }

CSS Grid

Menengah

🎯 Tujuan

Layout grid.

.grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; }

Media Queries

Menengah

🎯 Tujuan

Design responsif.

/* Tablet */ @media (max-width: 768px) { .container { grid-template-columns: 1fr; } }

Mobile First

Menengah

🎯 Tujuan

Design mobile dulu.

/* Desktop */ @media (min-width: 1024px) { .container { grid-template-columns: 1fr 2fr 1fr; } }

🎨 Praktik

Buat website responsif dengan header, navbar, layout grid, dan footer. Gunakan semantic HTML dan CSS modern untuk design profesional dan mobile-friendly.
