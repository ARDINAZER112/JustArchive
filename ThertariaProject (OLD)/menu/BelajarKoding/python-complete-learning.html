📖 Pengenalan Python

Apa itu Python?

Python adalah bahasa pemrograman tingkat tinggi yang dibuat pada tahun 1989 oleh Guido van Rossum. Python dirancang dengan fokus pada keterbacaan kode dan kesederhanaan. Bahasa ini telah menjadi salah satu bahasa pemrograman paling populer di dunia karena kemudahan penggunaan dan fleksibilitasnya.

Mengapa Python?

  • Mudah Dipelajari - Sintaks Python mirip dengan bahasa Inggris
  • Versatile - Bisa digunakan untuk web, data science, AI, automation, dll
  • Komunitas Besar - Ribuan library dan framework tersedia
  • Produktivitas Tinggi - Tulis kode lebih cepat dengan lebih sedikit baris
  • In-Demand - Salah satu bahasa paling dicari di industri tech

Aplikasi Python

🌐 Web Development: Django, Flask, FastAPI
📊 Data Science: NumPy, Pandas, Matplotlib
🤖 Artificial Intelligence: TensorFlow, PyTorch, scikit-learn
🔄 Automation: Scripting, task automation, web scraping
🎮 Game Development: Pygame
📱 Mobile: Kivy, BeeWare
☁️ Cloud: AWS, Google Cloud, Azure integration

🔧 Pemecahan Masalah Python

Bagian ini berisi masalah umum yang dihadapi saat belajar Python dan cara mengatasinya.

❌ Error: SyntaxError

📌 Penyebab:

Kesalahan penulisan kode Python - kurang tanda kurung, koma, colon, dll.

💡 Solusi:

Periksa baris yang ditunjukkan error dengan cermat. Pastikan semua tanda kurung, koma, dan colon sudah benar.

# ❌ SALAH print("Hello" # Kurang closing parenthesis # ✅ BENAR print("Hello")

❌ Error: NameError

📌 Penyebab:

Variabel belum didefinisikan atau nama salah ketika digunakan.

💡 Solusi:

Pastikan variabel sudah didefinisikan sebelum digunakan. Perhatikan huruf besar/kecil.

# ❌ SALAH print(name) # name tidak didefinisikan # ✅ BENAR name = "Budi" print(name)

❌ Error: TypeError

📌 Penyebab:

Operasi dilakukan pada tipe data yang tidak sesuai.

💡 Solusi:

Lakukan konversi tipe data dengan int(), str(), float(), dll sebelum operasi.

# ❌ SALAH umur = input("Umur: ") total = umur + 10 # TypeError: string + int # ✅ BENAR umur = int(input("Umur: ")) total = umur + 10

❌ Error: IndexError

📌 Penyebab:

Mengakses index yang tidak ada dalam list atau string.

💡 Solusi:

Pastikan index berada dalam range. Gunakan len() untuk melihat panjang list/string.

# ❌ SALAH fruits = ["apple", "banana", "cherry"] print(fruits[5]) # IndexError: index out of range # ✅ BENAR print(fruits[0]) # apple print(fruits[-1]) # cherry (index negatif)

❌ Error: KeyError

📌 Penyebab:

Mengakses key yang tidak ada dalam dictionary.

💡 Solusi:

Gunakan .get() method atau cek key sebelumnya dengan 'in' operator.

# ❌ SALAH person = {"name": "Budi", "age": 25} print(person["email"]) # KeyError: 'email' # ✅ BENAR print(person.get("email", "Not available")) # atau if "email" in person: print(person["email"])

❌ Error: IndentationError

📌 Penyebab:

Indentasi tidak konsisten (spasi atau tab).

💡 Solusi:

Gunakan konsistensi - 4 spasi atau tab. Perhatikan block code di if, for, function, dll.

# ❌ SALAH if x > 5: print("x lebih besar dari 5") # Indentasi salah # ✅ BENAR if x > 5: print("x lebih besar dari 5")

💡 Tips & Best Practices

🎯 Debug Dengan Print

Gunakan print() untuk melacak nilai variabel dan flow program Anda:

def calculate(a, b): print(f"a = {a}, b = {b}") # Debug result = a + b print(f"result = {result}") # Debug return result

✅ Gunakan Try-Except

Handle error dengan gracefully:

try: umur = int(input("Umur: ")) except ValueError: print("Masukkan angka yang valid!") except: print("Terjadi error!")

🔍 Baca Error Message

Error message memberikan informasi berharga. Baca dengan seksama:

  • Tipe error (SyntaxError, NameError, dll)
  • Pesan deskriptif
  • File dan line number dimana error terjadi
