📖 Pengenalan HTML & CSS

Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk membuat struktur halaman web. HTML menyediakan elemen-elemen (tags) yang mendefinisikan konten seperti judul, paragraf, gambar, link, dan banyak lagi. Setiap tag HTML memberitahu browser bagaimana menampilkan konten tersebut.

Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa styling yang digunakan untuk mengatur tampilan dan tata letak halaman web. CSS mengontrol warna, font, ukuran, jarak, positioning, dan banyak aspek visual lainnya dari elemen HTML. Dengan CSS, Anda dapat membuat website yang menarik dan responsif.

Mengapa HTML & CSS?

  • Fondasi Web - Setiap website dibangun dengan HTML dan CSS
  • Mudah Dipelajari - Sintaks yang sederhana dan intuitif
  • Universal - Bekerja di semua browser tanpa perlu instalasi
  • Fleksibel - Dapat digunakan dengan teknologi lain (JavaScript, PHP, dll)
  • SEO Friendly - Membantu search engine memahami konten
  • Mobile Friendly - Responsive design untuk semua perangkat

Perbedaan HTML vs CSS

HTML menangani STRUKTUR - membuat tulang punggung halaman web.
CSS menangani TAMPILAN - memberikan gaya dan layout ke struktur HTML.

Analogi: HTML seperti blueprint bangunan, CSS seperti cat dan dekorasi interior.

Cara Menggunakan HTML & CSS

<!-- Struktur dasar HTML --> <!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <title>Judul Halaman</title> <!-- 1. Internal CSS --> <style> body { background-color: #f0f0f0; font-family: Arial, sans-serif; } </style> </head> <body> <h1>Halo, Dunia!</h1> <!-- 2. Inline CSS --> <p style="color: red;">Ini adalah paragraf</p> <!-- 3. External CSS --> <link rel="stylesheet" href="style.css"> </body> </html>

📚 Tutorial HTML & CSS

Struktur Dasar HTML

Pemula

🎯 Tujuan

Memahami struktur dasar dokumen HTML.

💡 Konsep

Setiap halaman HTML dimulai dengan DOCTYPE dan tag html.

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width"> <title>Judul Halaman</title> </head> <body> <h1>Halo, Dunia!</h1> </body> </html>
💡 Tip: <head> berisi metadata, <body> berisi konten yang terlihat.

Heading & Paragraph

Pemula

🎯 Tujuan

Menggunakan heading dan paragraph untuk teks.

💡 Konsep

h1-h6 untuk judul, p untuk paragraf.

<h1>Judul Utama</h1> <h2>Sub Judul</h2> <h3>Sub Judul Lebih Kecil</h3> <p>Ini adalah paragraf pertama.</p> <p>Ini adalah paragraf kedua.</p> <!-- Teks dengan format --> <b>Teks Bold</b> <i>Teks Italic</i> <u>Teks Underline</u>

Pemula

🎯 Tujuan

CSS Selectors

Pemula

🎯 Tujuan

Memahami cara memilih elemen HTML dengan CSS.

/* Element Selector */ p { color: blue; } /* Class Selector */ .highlight { background: yellow; } /* ID Selector */ #header { background: navy; } /* Attribute Selector */ input[type="text"] { border: 1px solid gray; } /* Pseudo Selector */ a:hover { color: red; } button:active { transform: scale(0.95); } /* Combinators */ h1 + p { margin-top: 0; } /* Adjacent */ div > p { margin: 0; } /* Child */ ul li { list-style: none; } /* Descendant */

Warna & Font

Pemula

🎯 Tujuan

Mengatur warna dan jenis font teks.

body { /* Warna - berbagai format */ color: blue; /* Nama */ color: #ff0000; /* Hex */ color: rgb(255, 0, 0); /* RGB */ color: rgba(255, 0, 0, 0.5); /* RGBA */ /* Font */ font-family: Arial, sans-serif; font-size: 16px; font-weight: bold; /* atau 700 */ font-style: italic; line-height: 1.6; letter-spacing: 2px; text-align: center; } a { text-decoration: none; /* Hapus underline */ text-transform: uppercase; /* BESAR */ text-shadow: 2px 2px 4px gray; }

Box Model

Menengah

🎯 Tujuan

Memahami margin, padding, border, dan content.

.box { /* Padding - ruang di dalam */ padding: 20px; /* semua sisi */ padding: 10px 20px; /* atas-bawah, kiri-kanan */ padding-top: 10px; /* Border - garis pinggir */ border: 2px solid black; border-radius: 5px; /* sudut melengkung */ /* Margin - ruang di luar */ margin: 20px; /* semua sisi */ margin-bottom: 30px; /* Background */ background-color: lightgray; background-image: url('bg.jpg'); /* Width & Height */ width: 100%; height: 200px; max-width: 1200px; }

Background & Border

Menengah

🎯 Tujuan

Menata background dan border elemen.

/* Background */ div { background-color: #f0f0f0; background-image: url('pattern.png'); background-size: cover; /* cover, contain, 100% */ background-position: center; background-repeat: no-repeat; } /* Border */ button { border: 2px solid #333; border-top: 3px solid red; border-radius: 8px; /* sudut melengkung */ } /* Shadow */ .card { box-shadow: 0 4px 8px rgba(0,0,0,0.2); text-shadow: 1px 1px 2px gray; } /* Gradient */ header { background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); background: radial-gradient(circle, #667eea 0%, #764ba2 100%); }

Transition & Transform

Menengah

🎯 Tujuan

Membuat efek animasi CSS yang halus.

/* Transition */ button { background: blue; transition: all 0.3s ease; } button:hover { background: red; transform: scale(1.1); } /* Transform */ .box { transform: rotate(45deg); /* putar */ transform: scale(1.5); /* perbesar */ transform: translate(20px, 30px); /* pindah */ transform: skew(10deg); /* miring */ transform: scaleX(2) scaleY(0.5); transform-origin: center; } /* 3D Transform */ .card { transform: rotateX(30deg) rotateY(45deg); perspective: 1000px; }

Flexbox

Menengah

🎯 Tujuan

Menggunakan Flexbox untuk layout modern.

.container { display: flex; justify-content: center; /* center, space-between, space-around */ align-items: center; /* center, flex-start, flex-end */ gap: 20px; /* jarak antar item */ flex-direction: row; /* row, column */ flex-wrap: wrap; /* wrap, nowrap */ } .item { flex: 1; /* besar sama */ flex: 2; /* 2x lebih besar */ flex-grow: 1; /* tumbuh */ flex-shrink: 1; /* menyusut */ flex-basis: 200px; /* ukuran dasar */ }

CSS Grid

Menengah

🎯 Tujuan

Membuat layout grid yang kompleks.

.grid-container { display: grid; grid-template-columns: 1fr 2fr 1fr; /* 3 kolom */ grid-template-columns: repeat(3, 1fr); /* sama */ grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); grid-template-rows: 100px auto 100px; gap: 20px; grid-column-gap: 20px; grid-row-gap: 10px; } .item { grid-column: 1 / 3; /* span 2 kolom */ grid-row: 1 / 4; /* span 3 baris */ grid-area: header; }

Position

Menengah

🎯 Tujuan

Mengatur positioning elemen di halaman.

/* Static - default */ .element { position: static; } /* Relative - relative ke posisi normal */ .element { position: relative; top: 20px; left: 30px; } /* Absolute - relative ke parent */ .parent { position: relative; } .child { position: absolute; top: 10px; right: 10px; } /* Fixed - fixed di viewport */ .navbar { position: fixed; top: 0; width: 100%; z-index: 1000; } /* Sticky */ .header { position: sticky; top: 0; }

Media Query

Menengah

🎯 Tujuan

Membuat desain responsif untuk berbagai ukuran layar.

/* Desktop - Default */ .container { grid-template-columns: 1fr 2fr 1fr; font-size: 16px; } /* Tablet */ @media (max-width: 768px) { .container { grid-template-columns: 1fr 1fr; font-size: 14px; } .sidebar { display: none; } } /* Mobile */ @media (max-width: 480px) { .container { grid-template-columns: 1fr; font-size: 12px; } h1 { font-size: 24px; } } /* Media Query Lainnya */ @media print { /* Saat dicetak */ } @media (orientation: landscape) { /* Landscape */ } @media (prefers-dark-mode) { /* Dark Mode */ }

Mobile First Approach

Menengah

🎯 Tujuan

Desain untuk mobile dulu, kemudian desktop.

/* Mobile First - Default untuk layar kecil */ .container { grid-template-columns: 1fr; padding: 10px; } h1 { font-size: 24px; } /* Tablet dan lebih besar */ @media (min-width: 768px) { .container { grid-template-columns: 1fr 2fr; padding: 20px; } h1 { font-size: 32px; } } /* Desktop dan lebih besar */ @media (min-width: 1024px) { .container { grid-template-columns: 1fr 2fr 1fr; padding: 30px; } }

Responsive Units

Menengah

🎯 Tujuan

Menggunakan unit yang fleksibel.

/* Absolute Units */ width: 100px; /* pixel */ /* Relative Units */ width: 50%; /* persen */ width: 2em; /* relative ke font-size parent */ width: 2rem; /* relative ke font-size root */ width: 50vw; /* 50% viewport width */ width: 50vh; /* 50% viewport height */ width: 1vmin; /* 1% dari sisi lebih kecil */ width: 1vmax; /* 1% dari sisi lebih besar */ /* Rekomendasi */ font-size: 16px; /* base size */ h1 { font-size: 2rem; } /* 32px */ p { margin: 1rem; } /* 16px */ button { padding: 0.5rem 1rem; }
