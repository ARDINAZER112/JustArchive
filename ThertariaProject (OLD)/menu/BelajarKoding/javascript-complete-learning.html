📖 Pengenalan JavaScript

Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang dirancang untuk membuat halaman web interaktif dan dinamis. Awalnya dibuat oleh Brendan Eich pada tahun 1995, JavaScript telah berkembang menjadi salah satu bahasa pemrograman paling penting di dunia. Setiap browser modern menjalankan JavaScript untuk memberikan pengalaman pengguna yang interaktif.

Mengapa JavaScript?

  • Universal - Berjalan di semua browser tanpa perlu instalasi
  • Interaktif - Membuat website responsive dan user-friendly
  • Versatile - Bisa untuk frontend, backend (Node.js), mobile, dll
  • Mudah Dipelajari - Sintaks yang sederhana dan intuitif
  • Komunitas Besar - Ribuan library dan framework tersedia

Aplikasi JavaScript

🌐 Web Development: React, Vue, Angular, Next.js
💻 Backend: Node.js, Express, NestJS
📱 Mobile: React Native, Flutter
🎮 Game Development: Phaser, Babylon.js
🤖 Machine Learning: TensorFlow.js
📊 Data Visualization: D3.js, Chart.js
⚡ Real-time Apps: WebSocket, Socket.io

Cara Menggunakan JavaScript

<!-- 1. Inline JavaScript --> <button onclick="alert('Hello')">Klik Me</button> <!-- 2. Internal Script --> <script> console.log('Hello, JavaScript!'); </script> <!-- 3. External Script --> <script src="script.js"></script>

🔧 Pemecahan Masalah JavaScript

Bagian ini berisi masalah umum yang dihadapi saat belajar JavaScript dan cara mengatasinya.

❌ Error: ReferenceError

📌 Penyebab:

Variabel atau fungsi belum didefinisikan atau nama salah ketika digunakan.

💡 Solusi:

Pastikan variabel sudah didefinisikan sebelum digunakan. Perhatikan huruf besar/kecil dan typo.

// ❌ SALAH console.log(name); // ReferenceError: name is not defined // ✅ BENAR let name = "Budi"; console.log(name);

❌ Error: TypeError

📌 Penyebab:

Operasi dilakukan pada tipe data yang tidak sesuai atau calling method yang tidak ada.

💡 Solusi:

Periksa tipe data dengan typeof dan pastikan method ada pada object tersebut.

// ❌ SALAH let number = 5; console.log(number.toUpperCase()); // TypeError // ✅ BENAR let text = "hello"; console.log(text.toUpperCase()); // HELLO // ❌ SALAH let obj = null; console.log(obj.name); // TypeError: Cannot read property 'name' of null // ✅ BENAR let obj = {name: "Budi"}; console.log(obj.name); // Budi

❌ Error: Undefined Variable

📌 Penyebab:

Variabel dideklarasikan tapi belum diberi nilai atau fungsi tidak return value.

💡 Solusi:

Selalu berikan nilai awal atau gunakan default value dalam function.

// ❌ SALAH let result; console.log(result); // undefined // ✅ BENAR let result = 0; // atau nilai default lainnya console.log(result); // ❌ SALAH function getValue() { let value = 10; // Tidak ada return } // ✅ BENAR function getValue() { let value = 10; return value; }

❌ Error: This Context

📌 Penyebab:

Menggunakan arrow function dalam object method atau event listener.

💡 Solusi:

Gunakan function biasa (tidak arrow) atau bind this ke function.

// ❌ SALAH let obj = { name: "Budi", greet: () => { console.log(this.name); // undefined } }; // ✅ BENAR let obj = { name: "Budi", greet: function() { console.log(this.name); // Budi } }; // ✅ JUGA BENAR - Bind let obj2 = { name: "Andi", greet: (() => { console.log(this.name); }).bind(obj2) };

❌ Error: Async/Await

📌 Penyebab:

Lupa await saat memanggil async function atau tidak ada try-catch untuk error handling.

💡 Solusi:

Selalu gunakan await dan wrap dalam try-catch.

// ❌ SALAH async function main() { let data = fetchData(); // Promise, bukan data console.log(data); // Promise object } // ✅ BENAR async function main() { let data = await fetchData(); console.log(data); // Actual data } // ❌ SALAH async function getUser() { let user = await fetch("/api/user"); return user; // Tidak bisa di-await } // ✅ BENAR async function getUser() { try { let response = await fetch("/api/user"); let user = await response.json(); return user; } catch (error) { console.log("Error: " + error); } }

❌ Error: Index Out of Range

📌 Penyebab:

Mengakses array index yang tidak ada.

💡 Solusi:

Periksa panjang array sebelum akses atau gunakan optional chaining (?.).

// ❌ SALAH let arr = [1, 2, 3]; console.log(arr[5]); // undefined (tidak error, tapi wrong result) // ✅ BENAR let arr = [1, 2, 3]; if (arr.length > 5) { console.log(arr[5]); } // ✅ JUGA BENAR - Optional chaining console.log(arr?.[5]); // undefined (aman)

💡 Tips & Best Practices

🎯 Debug dengan Browser Console

Gunakan console methods untuk debug:

console.log("Log"); console.error("Error message"); console.warn("Warning message"); console.table(data); console.time("timer"); // ... kode console.timeEnd("timer"); console.trace(); // Stack trace

✅ Gunakan Strict Mode

Aktifkan strict mode untuk lebih banyak error checking:

"use strict"; // Sekarang akan error x = 3.14; // ReferenceError // Di non-strict mode, x akan jadi global variable

🔍 Gunakan DevTools

  • F12 atau Ctrl+Shift+I untuk buka DevTools
  • Console tab untuk debug
  • Debugger breakpoints untuk step through code
  • Network tab untuk monitor API calls
  • Elements tab untuk inspect HTML dan CSS

📚 Gunakan Linter (ESLint)

ESLint membantu menemukan masalah dalam kode sebelum runtime:

  • Install ESLint untuk project Anda
  • Setup .eslintrc untuk rules
  • Integrate dengan VS Code
  • Auto-fix dengan --fix flag
