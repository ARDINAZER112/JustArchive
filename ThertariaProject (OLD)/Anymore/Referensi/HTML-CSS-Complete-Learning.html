🏗️ HTML Dasar

Pemula

📖 Deskripsi

Pelajari fondasi HTML - memahami tags, elements, atribut, dan cara membuat struktur halaman web yang baik. HTML adalah bahasa markup yang memberitahu browser bagaimana menampilkan konten.

🎯 Apa yang Akan Dipelajari

  • Struktur dasar HTML document
  • HTML tags dan elements
  • Heading, paragraph, dan text formatting
  • Link dan gambar
  • List dan table
  • Form dan input elements

Struktur Dasar HTML

Setiap halaman HTML dimulai dengan DOCTYPE dan struktur dasar ini:

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width"> <title>Judul Halaman</title> </head> <body> <h1>Halo, Dunia!</h1> </body> </html>

Tags HTML Umum

<h1>Heading 1</h1> <p>Paragraf</p> <!-- Link --> <a href="https://google.com">Kunjungi Google</a> <!-- Gambar --> <img src="photo.jpg" alt="Deskripsi"> <!-- List --> <ul> <li>Item 1</li> <li>Item 2</li> </ul> <!-- Text Formatting --> <b>Bold</b> <i>Italic</i> <u>Underline</u>

Form Elements

<form action="/submit" method="POST"> <label for="name">Nama:</label> <input type="text" id="name" name="name"> <label for="email">Email:</label> <input type="email" id="email" name="email"> <label for="message">Pesan:</label> <textarea id="message" name="message" rows="5"></textarea> <button type="submit">Kirim</button> </form>

🎨 CSS Dasar

Pemula

📖 Deskripsi

Pelajari CSS untuk styling halaman web. Kontrol warna, font, layout, dan visual elements lainnya. CSS membuat halaman HTML Anda terlihat menarik dan profesional.

🎯 Apa yang Akan Dipelajari

  • CSS selectors dan properties
  • Box model (margin, padding, border)
  • Colors dan fonts
  • Backgrounds dan borders
  • Display dan positioning
  • Flexbox dan Grid basics

CSS Selectors

/* Element Selector */ p { color: blue; } /* Class Selector */ .highlight { background: yellow; } /* ID Selector */ #header { background: navy; } /* Attribute Selector */ input[type="text"] { border: 1px solid gray; } /* Pseudo Selector */ a:hover { color: red; } button:active { transform: scale(0.95); }

Box Model

.box { /* Padding - ruang dalam */ padding: 20px; /* Border - garis pinggir */ border: 2px solid black; border-radius: 5px; /* Margin - ruang luar */ margin: 20px; /* Width & Height */ width: 100%; height: 200px; }

Warna & Font

body { /* Warna */ color: blue; /* nama */ color: #ff0000; /* hex */ color: rgb(255, 0, 0); /* rgb */ background: #f0f0f0; /* Font */ font-family: Arial, sans-serif; font-size: 16px; font-weight: bold; line-height: 1.6; }

✨ CSS Lanjut

Intermediate - Advanced

📖 Deskripsi

Kuasai teknik CSS tingkat lanjut termasuk Flexbox, Grid, positioning, animations, dan responsive design. Buat layout profesional dan animasi yang smooth.

🎯 Apa yang Akan Dipelajari

  • Flexbox layout - alignment & distribution
  • CSS Grid - layout template
  • Positioning - absolute, relative, fixed
  • Transforms & animations
  • Media queries & responsive design
  • CSS preprocessors (SCSS)
/* Flexbox */ .container { display: flex; justify-content: center; align-items: center; gap: 20px; } /* Grid */ .grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; } /* Animation */ @keyframes slide { from { transform: translateX(0); } to { transform: translateX(100px); } } .box { animation: slide 2s infinite; }

🔧 Penyelesaian Masalah HTML & CSS

Latihan soal untuk menguji pemahaman Anda tentang HTML dan CSS. Setiap soal dirancang untuk memperkuat konsep tertentu.

Soal 1: Membuat Website Card

MUDAH
🎯 Tujuan:

Buatlah sebuah card HTML dengan judul, gambar, deskripsi, dan tombol, kemudian styling dengan CSS agar terlihat menarik.

📋 Persyaratan:
  • Card dengan background putih dan shadow
  • Gambar di bagian atas
  • Judul dan deskripsi
  • Tombol dengan hover effect
  • Padding dan spacing yang rapi
💡 Tips:
Gunakan CSS untuk: border-radius, box-shadow, padding, margin, dan transition

Soal 2: Responsive Navigation Bar

SEDANG
🎯 Tujuan:

Buat navigation bar yang responsif - horizontal di desktop, vertikal/hamburger menu di mobile.

📋 Persyaratan:
  • Logo atau title di sebelah kiri
  • Menu links di sebelah kanan
  • Fixed position di atas halaman
  • Responsive untuk mobile
  • Hover effect pada menu items
  • Smooth transitions
💡 Tips:
Gunakan: Flexbox untuk layout, media queries untuk responsive, dan ::after pseudo-element untuk underline effect

Soal 3: Landing Page Lengkap

SULIT
🎯 Tujuan:

Buat landing page dengan beberapa section - header, features, testimonials, footer dengan styling yang konsisten.

📋 Persyaratan:
  • Header dengan call-to-action button
  • Features section dengan cards grid
  • Testimonials section
  • Footer dengan links
  • Responsive design (mobile, tablet, desktop)
  • Smooth scroll navigation
  • Consistent color scheme dan typography
  • Hover effects dan animations
💡 Tips:
Struktur: Gunakan semantic HTML (header, main, section, footer)
Layout: Flexbox dan Grid untuk flexible layouts
Responsive: Mobile-first approach dengan media queries
