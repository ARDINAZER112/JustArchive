📖 Pengenalan JavaScript

Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang dirancang untuk membuat halaman web interaktif dan dinamis. Awalnya dibuat oleh Brendan Eich pada tahun 1995, JavaScript telah berkembang menjadi salah satu bahasa pemrograman paling penting di dunia.

Mengapa JavaScript?

  • Universal - Berjalan di semua browser tanpa instalasi
  • Interactive - Membuat website responsive dan user-friendly
  • Versatile - Bisa untuk frontend, backend, mobile, dll
  • Easy to Learn - Sintaks yang sederhana dan intuitif
  • Large Community - Ribuan library dan framework
// Cara menggunakan JavaScript // 1. Inline <button onclick="alert('Hello')">Click</button> // 2. Internal <script> console.log('Hello, JavaScript!'); </script> // 3. External <script src="script.js"></script>

📚 Tutorial JavaScript

Hello World

Pemula

🎯 Tujuan

Program pertama Anda dalam JavaScript.

console.log("Hello, World!");

Variabel

Pemula

🎯 Tujuan

Menyimpan dan menggunakan data dalam program.

let nama = "Budi"; let umur = 20; const PI = 3.14; console.log(nama); // Budi console.log(umur); // 20

Operator

Pemula

🎯 Tujuan

Melakukan operasi matematika dan perbandingan.

let a = 10, b = 3; console.log(a + b); // 13 console.log(a > b); // true console.log(a === b); // false

Tipe Data

Pemula

🎯 Tujuan

Memahami berbagai tipe data JavaScript.

let num = 42; let text = "hello"; let flag = true; let arr = [1, 2, 3]; let obj = {name: "Budi"};

Array

Menengah

🎯 Tujuan

Menyimpan multiple items dalam satu variabel.

let fruits = ["apple", "banana"]; console.log(fruits[0]); // apple console.log(fruits.length); // 2 fruits.push("grape"); // Tambah

Object

Menengah

🎯 Tujuan

Menyimpan data dengan key-value pairs.

If Statement

Pemula

🎯 Tujuan

Membuat keputusan berdasarkan kondisi.

let age = 18; if (age >= 18) { console.log("Dewasa"); } else { console.log("Anak-anak"); }

For Loop

Pemula

🎯 Tujuan

Mengulang kode dengan jumlah tertentu.

for (let i = 0; i < 5; i++) { console.log(i); }

While Loop

Pemula

🎯 Tujuan

Mengulang selama kondisi terpenuhi.

let i = 0; while (i < 5) { console.log(i); i++; }

Function Basics

Menengah

🎯 Tujuan

Arrow Functions

Menengah

🎯 Tujuan

Syntax yang lebih singkat untuk function.

Callbacks

Lanjut

🎯 Tujuan

Function yang dikirim sebagai parameter.

DOM Events

Menengah

🎯 Tujuan

Creating Elements

Menengah

🎯 Tujuan

Promises

Lanjut

🎯 Tujuan

Menangani operasi async dengan Promise.

let promise = new Promise((resolve) => { setTimeout(() => resolve("Done"), 1000); }); promise.then(r => console.log(r));

Async/Await

Lanjut

🎯 Tujuan

Syntax yang lebih clean untuk Promise.

async function getData() { let data = await fetch(url); return await data.json(); }

Fetch API

Lanjut

🎯 Tujuan

Membuat HTTP request ke server.

fetch("https://api.example.com/data") .then(r => r.json()) .then(d => console.log(d));

🔧 Pemecahan Masalah

❌ ReferenceError

📌 Penyebab:

Variabel atau function belum didefinisikan.

💡 Solusi:

Pastikan variabel sudah didefinisikan sebelum digunakan.

// ❌ SALAH console.log(name); // ✅ BENAR let name = "Budi"; console.log(name);

❌ TypeError

📌 Penyebab:

Operasi pada tipe data yang tidak sesuai.

💡 Solusi:

Periksa tipe data dengan typeof.

// ❌ SALAH let num = 5; console.log(num.toUpperCase()); // ✅ BENAR let text = "hello"; console.log(text.toUpperCase());

Konsep-konsep Penting

  • Variables: Variabel adalah wadah untuk data, yang dideklarasikan menggunakan `let`, `const`, atau `var`. Disarankan untuk menggunakan `const` secara default dan `let`
  • Equality: JavaScript memiliki operator kesamaan (==), yang melakukan konversi tipe, dan operator kesamaan ketat (===), yang memeriksa nilai dan tipe.
  • References vs. Values: VTipe data primitif (seperti angka dan string) dilewatkan berdasarkan nilai, sedangkan objek dan array dilewatkan berdasarkan referensi. Ini berarti memodifikasi objek yang direferensikan di dalam suatu fungsi akan mengubah objek aslinya.
  • [.this] Keyword: Nilai ` this` berubah tergantung pada bagaimana sebuah fungsi dipanggil (pengikatan saat runtime). Fungsi panah mewarisi `this` dari cakupan induknya, yang merupakan perbedaan utama dari fungsi tradisional.
