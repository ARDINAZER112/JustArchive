📖 Pengenalan Python

Apa itu Python?

Python adalah bahasa pemrograman tingkat tinggi yang dibuat pada tahun 1989 oleh Guido van Rossum. Python dirancang dengan fokus pada keterbacaan kode dan kesederhanaan. Bahasa ini telah menjadi salah satu bahasa pemrograman paling populer di dunia karena kemudahan penggunaan dan fleksibilitasnya.

Mengapa Python?

  • Mudah Dipelajari

    Sintaks Python mirip dengan bahasa Inggris

  • Versatile

    Bisa digunakan untuk web, data science, AI, automation, dll

  • Komunitas Besar

    Ribuan library dan framework tersedia

  • Produktivitas Tinggi

    Tulis kode lebih cepat dengan lebih sedikit baris

  • In-Demand

    Salah satu bahasa paling dicari di industri tech

Instalasi Python

Periksa apakah Python sudah terinstal

Buka terminal Anda dan periksa versi Python 3 yang terpasang dengan perintah

python --version

Windows:

Download dari - dan jalankan installer

python.org

Atau memakai terminal (win + R lalu ketik cmd)

winget search python

kemudian

winget install Python.Python.3

MacOS:

brew install python3

Linux:

For Debian/Ubuntu/Mint/Kali Linux

sudo apt-get install python3

For Fedora/RHEL/CentOS

sudo dnf install python3 # or sudo yum install python3

For Arch Linux

sudo pacman -S python

Function Basics

Intermediate

🎯 Tujuan

Membuat dan menggunakan function.

def greet(name): return f"Halo, {name}!" result = greet("Budi") print(result) def add(a, b): return a + b print(add(5, 3)) # 8

Default Parameters

Intermediate

🎯 Tujuan

Function dengan default values.

*args & **kwargs

Advanced

🎯 Tujuan

Flexible parameters.

def sum_numbers(*args): return sum(args) print(sum_numbers(1, 2, 3, 4)) # 10 def print_info(**kwargs): for key, value in kwargs.items(): print(f"{key}: {value}")

Lambda Functions

Advanced

🎯 Tujuan

Anonymous functions satu baris.

square = lambda x: x ** 2 print(square(5)) # 25 add = lambda x, y: x + y print(add(3, 5)) # 8

Maps and Filters

Advanced

🎯 Tujuan

Transform & filter data.

nums = [1, 2, 3, 4, 5] squared = list(map(lambda x: x**2, nums)) # [1, 4, 9, 16, 25] even = list(filter(lambda x: x % 2 == 0, nums)) # [2, 4]

Decorators

Advanced

🎯 Tujuan

Enhance functions.

def decorator(func): def wrapper(): print("Before") func() print("After") return wrapper @decorator def say_hello(): print("Hello!") say_hello()

Class & Object

Advanced

🎯 Tujuan

Membuat class dan object.

class Person: def __init__(self, name, age): self.name = name self.age = age def introduce(self): return f"I'm {self.name}" p = Person("Budi", 25) print(p.introduce())

Inheritance

Advanced

🎯 Tujuan

Mewarisi dari class lain.

class Animal: def speak(self): print("Sound") class Dog(Animal): def speak(self): print("Bark") dog = Dog() dog.speak() # Bark

Polymorphism

Advanced

🎯 Tujuan

Berbagai object, interface sama.

class Cat: def speak(self): return "Meow" class Dog: def speak(self): return "Woof" def animal_sound(animal): print(animal.speak()) animal_sound(Cat()) # Meow animal_sound(Dog()) # Woof

Encapsulation

Advanced

🎯 Tujuan

Membatasi akses ke data.

class Bank: def __init__(self, balance): self.__balance = balance def deposit(self, amount): self.__balance += amount def get_balance(self): return self.__balance

@property

Advanced

🎯 Tujuan

Getter dan setter.

class Circle: def __init__(self, radius): self._radius = radius @property def area(self): return 3.14 * self._radius ** 2 c = Circle(5) print(c.area) # 78.5

Static Methods

Advanced

🎯 Tujuan

Methods yang tidak perlu self.

class Math: @staticmethod def add(a, b): return a + b @classmethod def from_string(cls, s): return cls(*map(int, s.split())) print(Math.add(5, 3)) # 8

🔧 Pemecahan Masalah Python

❌ SyntaxError

📌 Penyebab:

Kesalahan penulisan kode - kurang colon, indentasi salah, dll.

💡 Solusi:

Periksa baris yang ditunjukkan error dengan cermat.

# ❌ FALSE if x > 5 print("x lebih besar") # ✅ TRUE if x > 5: print("x lebih besar")

❌ NameError

📌 Penyebab:

Variabel belum didefinisikan atau nama salah.

💡 Solusi:

Pastikan variabel sudah didefinisikan sebelum digunakan.

# ❌ FALSE print(name) # name tidak didefinisikan # ✅ TRUE name = "Budi" print(name)

❌ TypeError

📌 Penyebab:

Operasi pada tipe data yang tidak sesuai.

💡 Solusi:

Lakukan konversi tipe data sebelum operasi.

# ❌ FALSE umur = input("Umur: ") total = umur + 10 # TypeError # ✅ TRUE umur = int(input("Umur: ")) total = umur + 10

❌ IndexError

📌 Penyebab:

Mengakses index yang tidak ada.

💡 Solusi:

Pastikan index berada dalam range.

# ❌ FALSE fruits = ["apple", "banana"] print(fruits[5]) # IndexError # ✅ TRUE print(fruits[0]) # apple print(fruits[-1]) # banana

❌ IndentationError

📌 Penyebab:

Indentasi tidak konsisten.

💡 Solusi:

Gunakan 4 spasi atau tab konsisten.

# ❌ FALSE if x > 5: print("x lebih besar") # ✅ TRUE if x > 5: print("x lebih besar")
